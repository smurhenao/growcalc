# GrowCalc 🌱

Calculadora de nutrientes para cultivos basada en la tabla oficial de Soul Sensei.

## Características

- Cálculo automático.
- Selección de etapa.
- Selección de semana.
- Conversión automática de litros a galones.
- Actualización en tiempo real.
- Diseño responsive.

## Tecnologías

- HTML5
- CSS3
- JavaScript ES Modules
